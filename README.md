# Plataforma de Capacitación CAIPA

Prototipo navegable de la plataforma de capacitación del Modelo CAIPA (escritorio y celular).

- **Prototipo:** carpeta [`prototipo/`](prototipo/) — ver [`prototipo/LEEME.md`](prototipo/LEEME.md).
- **Ver en local:** `powershell -ExecutionPolicy Bypass -File servidor.ps1` y abrir http://localhost:8080

Versión final planeada: Apps Script + Google Sheets, insertada en Google Sites.
